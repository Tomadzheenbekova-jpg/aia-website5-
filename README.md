# АЙА (AIA) — сайт бренда

Черновая версия сайта бренда женской одежды АЙА. Next.js 14
(App Router), TypeScript, Tailwind CSS. Двуязычный: русский и
английский, с переключателем языка.

## Языки сайта (RU/EN)

Сайт полностью двуязычный:

- Структура маршрутов: `/ru/...` и `/en/...` (например `/ru/kollektsii`,
  `/en/kollektsii`). Заход на `/` автоматически определяет язык
  по браузеру посетителя и делает редирект на `/ru` или `/en`
  (см. `middleware.ts`), по умолчанию — русский.
- Все переводимые тексты сайта живут в
  `lib/i18n/dictionaries/ru.ts` и `lib/i18n/dictionaries/en.ts`.
  Структура обоих файлов задана типом `Dictionary` в
  `lib/i18n/types.ts` — если добавляете новый текст, впишите его
  в тип и в оба словаря, иначе TypeScript укажет на пропуск.
- Названия и описания категорий каталога — тоже в словарях
  (ключ `categories.<slug>`), а не в `lib/categories.ts` (там
  остались только фото и структура галерей).
- Переключатель языка — компонент `components/LocaleSwitcher.tsx`,
  показан в шапке сайта (десктоп и мобильная версия).
- Уведомления о заявках в Telegram/email всегда приходят на русском,
  независимо от языка сайта у покупателя, — это сделано намеренно
  для удобства команды.

## Что уже сделано

- Главная страница, «О бренде», «Наше производство», «Коллекции»
  (9 категорий, включая куртки), «Контрактное производство» (с формой
  заявки), «Контакты» (с формой обратной связи), «Политика
  конфиденциальности», «Согласие на обработку персональных данных»,
  страница 404 — всё на двух языках.
- Форма прямого заказа на сайте (`/kollektsii`).
- Форма заявки на контрактное производство (`/kontraktnoe-proizvodstvo`).
- Форма обратной связи (`/kontakty`).
- Все три формы отправляют заявку в Telegram-бота (в закрытую рабочую
  группу) и дублируют на email — см. настройку ниже.
- Кнопки «Купить на Wildberries» и ссылки на WhatsApp/Telegram
  автоматически скрываются, пока в `lib/site-config.ts` не указаны
  реальные ссылки — сайт никогда не ведёт в никуда и не имитирует
  несуществующие каналы связи.
- Реальные фото товаров с фирменным водяным знаком «АЙА / AIA».
- SEO: `sitemap.xml` (обе локали), `robots.txt`, метаданные и
  Open Graph теги на каждой странице и на каждом языке.

## Что нужно донастроить перед публикацией

1. **Ссылки и контакты** — заполнить `lib/site-config.ts`:
   ссылка на магазин Wildberries, Telegram-канал, телефон, WhatsApp,
   email.
2. **Юридические данные** — заполнить блок `legal` в
   `lib/site-config.ts` (юр. наименование, ИНН, рег. номер, юр. адрес,
   реквизиты, оператор персональных данных). Пока не заполнено — на
   сайте эти поля показывают `[ЗАПОЛНИТЬ ПОЗЖЕ]` / `[TO BE ADDED]`.
3. **Telegram-бот и почта** — создать `.env.local` на основе
   `.env.example` и заполнить:
   - `TELEGRAM_BOT_TOKEN`, `TELEGRAM_GROUP_CHAT_ID` — для приёма заявок
     в закрытую рабочую группу;
   - `SMTP_HOST`, `SMTP_USER`, `SMTP_PASS`, `NOTIFICATIONS_EMAIL` —
     для дублирования заявок на почту. В `lib/email.ts` оставлена
     точка подключения реального SMTP-клиента (например,
     `nodemailer`) — сейчас функция честно возвращает ошибку, а не
     имитирует отправку.
4. **Фотографии** — добавить фото для категорий «Блузки» и «Жакеты»
   (пока плейсхолдеры) в `public/images/categories/` и прописать пути
   в `lib/categories.ts`.
5. **Домен** — после проверки чернового сайта на Vercel подключить
   собственный домен и заменить `https://yes-today.example` на реальный
   в `app/[locale]/layout.tsx`, `app/sitemap.ts`.

## Запуск локально

```bash
npm install
cp .env.example .env.local   # заполнить значения
npm run dev
```

Сайт откроется на http://localhost:3000 и автоматически перенаправит
на `/ru` или `/en`.

## Публикация на Vercel

1. Создать новый отдельный проект на [vercel.com](https://vercel.com),
   не связанный с другими ботами/интеграциями.
2. Подключить репозиторий с этим проектом.
3. В настройках проекта на Vercel добавить переменные окружения из
   `.env.example` (Settings → Environment Variables).
4. Deploy. Vercel автоматически определит Next.js проект.
5. После проверки — подключить домен во вкладке Domains.
