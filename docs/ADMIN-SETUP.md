# Панель управления АЙА

Репозиторий: Tomadzheenbekova-jpg/aia-website5-. Vercel: aia-website5.
Адрес панели: /admin. Не подключать другие проекты или Wildberries.

## Однократная настройка

1. Создать отдельный проект Supabase для этого сайта. Включить вход email/password,
   отключить публичную регистрацию. Пароль владельца задаётся в интерфейсе Supabase,
   его нельзя добавлять в GitHub, код или переписку.
2. Выполнить supabase/aia-cms.sql в SQL Editor этого нового проекта.
3. Создать подтверждённую учётную запись владельца в Authentication > Users.
   Внести её UUID в public.aia_editors командой из конца SQL-файла.
   Самостоятельная регистрация не предоставляет права редактора.
4. Только в проект aia-website5 добавить переменные Vercel:
   NEXT_PUBLIC_SUPABASE_URL — URL проекта;
   NEXT_PUBLIC_SUPABASE_ANON_KEY — публичный anon/publishable API key.
   Не использовать service_role или secret key: эти переменные доступны браузеру.
5. Пересобрать deployment. Для проверки Preview использовать отдельный тестовый
   Supabase project, чтобы проверочные изменения не попадали в Production.
6. Проверить вход владельца, отказ постороннему пользователю и анонимной записи,
   загрузку JPG с телефона, публикацию галереи и текстов RU/EN, сохранность после
   повторного входа, отказ при конфликтующих публикациях из двух окон.

## Использование

Войти по email и паролю → выбрать «Фотографии», категорию → загрузить снимки →
при необходимости выбрать обложку → «Опубликовать изменения».
Раздел «Логотипы» управляет двумя логотипами отдельно.
Раздел «Тексты» содержит поля для русского и английского текста.
После публикации открыть сайт в новой вкладке или обновить страницу.
Загрузка сама по себе не публикует фото. После обновления панели нужен новый вход;
несохранённые изменения будут потеряны, браузер предупредит об этом.
Сессия хранится только в памяти вкладки. При истечении сеанса скопировать
несохранённые тексты и войти снова. Восстановление пароля — через администратора
Supabase. Самостоятельное восстановление с почтой пока не включено.

## Технические границы

Сохраняются категории/галереи, два логотипа и строки словарей. Контакты из
lib/site-config.ts и декоративные фотографии в блоках главной/бренда пока не
редактируются в панели. Изменения текста не переводятся автоматически.
База хранит один опубликованный документ с номером версии. Сравнение номера
предотвращает затирание изменений из другого окна.
Фото получают уникальные имена. Удаление из категории не удаляет файл из
хранилища, чтобы не ломать старые ссылки. Периодическую очистку следует выполнять
отдельно после проверки использования.
При недоступности хранилища публичный сайт показывает исходное содержимое из кода;
после восстановления соединения снова отображаются опубликованные изменения.
Пока переменных окружения нет, /admin показывает статус настройки и не принимает
логин/загрузки. Не объявлять панель работающей до реальной проверки подключения.
